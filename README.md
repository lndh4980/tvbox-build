# TVBox-Swift TrollStore Auto Build

Automatically build iOS IPA for TrollStore installation.

## Download

Check [Releases](../../releases) for the latest IPA.

## Install

1. Download `TVBox-TrollStore.ipa`
2. Transfer to iPhone (AirDrop/WeChat/iCloud)
3. Open with TrollStore to install

## Requirements

- iOS 17.0+
- TrollStore 2.0+

## Features

- ✅ Auto build on every commit
- ✅ No signing required (TrollStore only)
- ✅ Clean build from source
